# САДХАНА — сайт закрытого клуба практики

Одностраничный сайт для закрытого Telegram-клуба: хатха-йога в традиции Иша,
каларипаятту, аюрведа, мантры и киртан. Русский язык, молочно-земляная палитра,
плавные анимации на GSAP.

```
projects/yoga-club-ru/
├── index.html              # вся разметка страницы
├── assets/
│   ├── css/styles.css      # дизайн-система и все стили
│   ├── js/main.js          # интерактив и анимации
│   └── img/                # 7 изображений (см. раздел «Изображения»)
└── README.md               # этот файл
```

Сборка не нужна: это статические файлы. Откройте `index.html` в браузере
или загрузите папку на любой хостинг.

Тексты в разделе «Голоса круга» — **заготовки для вёрстки, а не настоящие отзывы**.
Публиковать выдуманные отзывы нельзя: это вводит людей в заблуждение и подпадает
под закон «О рекламе». Замените их реальными словами реальных участников с их
согласия — или удалите секцию целиком (блок `<section id="voices">`
и пункт «Отзывы» в двух меню).

### ⚠️ Про аюрведу и здоровье

В FAQ и в подвале стоят honest-дисклеймеры: занятия не являются медицинской
услугой. Не убирайте их и не добавляйте обещаний лечения — это и юридический
риск, и вопрос доверия.

| `divider-haze.jpg` | фон блока-манифеста | 2000×620, широкий | Спокойный горизонтальный кадр, много воздуха |

Шесть кадров бегущей галереи берутся из этого же набора — замените их
на любые шесть вертикальных фотографий (блок помечен в разметке).

**Как заменить:** положите свой файл в `assets/img/` под тем же именем —
и всё. Пропорции, обрезка, ленивая загрузка, параллакс и анимация появления
уже настроены. Если имя другое, поправьте `src` в отмеченных строках.

**Совет по весу:** держите каждый файл в пределах 250–400 КБ
(экспорт JPEG качеством 80 или WebP). Сейчас все изображения вместе
занимают около 950 КБ, разметка со стилями и скриптом — 140 КБ.
Первый экран грузит только одно изображение, остальные подгружаются по мере
прокрутки (`loading="lazy"`).

## 3. Дизайн-система

Всё настраивается переменными в начале `assets/css/styles.css` (блок `:root`).

**Палитра** — молочная база, глубокая зелень, тёплая глина:

| Токен | Значение | Роль |
|---|---|---|
| `--bg` | `#FAF6EE` | молочный фон |
| `--bg-alt` | `#F2EBDD` | песочный фон чередующихся секций |
| `--surface` | `#FFFDF8` | карточки |
| `--forest-deep` | `#1F2A22` | тёмные секции |
| `--text` | `#26332A` | основной текст |
| `--clay` | `#7A4F32` | акцент, кнопки, ссылки |
| `--sage` | `#7D9075` | зелёный акцент |

Все сочетания проверены по WCAG: основной текст — 12.3:1 (AAA),
приглушённый — 5.9:1 (AA), акцентная глина — 6.5:1 (AA),
светлый текст на тёмной секции — 13:1 (AAA).

**Шрифты:** Cormorant Garamond (заголовки) + Manrope (текст).
Оба содержат кириллицу; подключаются с Google Fonts и имеют
системные запасные варианты, если шрифты не загрузятся.

**Типографика и отступы** заданы через `clamp()` — размеры плавно
меняются от телефона к десктопу без «скачков» на промежуточных ширинах.

## 4. Анимации

Библиотека GSAP 3.13 + ScrollTrigger, подключаются с CDN.

| Что | Где |
|---|---|
| Построчное раскрытие заголовков | все `h1`/`h2` в `.line-mask` |
| Появление блоков при прокрутке | атрибут `data-reveal` |
| Прорисовка линейных иконок | атрибут `data-draw` |
| Параллакс фоновых пятен | атрибут `data-parallax` |
| Круг дыхания 4 сек / 6 сек | `#breath` |
| Бегущая строка и вращающаяся печать | `[data-marquee]`, `#seal` |
| Экран загрузки: логотип прорисовывается, шкала, шторка уходит вверх | `#loader` (~1.4 сек) |
| Закреплённая лента направлений — прокрутка вбок | `[data-rail]` (от 992 px) |
| Манифест: слова загораются по мере прокрутки | `[data-words]` |
| Шторка: изображение открывается снизу вверх | `[data-curtain]` |
| Параллакс внутри рамок изображений | `[data-parallax-img]` |
| Бегущая галерея | `[data-strip]` |
| Липкая стопка «три шага» | `[data-stack]` |
| Кольцо-курсор и магнитные кнопки | только для мыши, `hover: hover` |

**Три уровня надёжности:**

1. Если JavaScript выключен — начальные состояния анимаций вообще не
   применяются (класс `.js` ставится инлайн-скриптом), страница видна целиком.
2. Если GSAP не загрузился с CDN — ставится класс `.motion-off`,
   всё содержимое показывается сразу.
3. Если в системе включено «уменьшить движение»
   (`prefers-reduced-motion`) — анимации не запускаются, а бесконечные
   (дыхание, бегущая строка, печать) не создаются вовсе.

Непрерывные анимации останавливаются, когда уходят за пределы экрана
или когда вкладка неактивна, — чтобы не тратить батарею на телефоне.

**Хотите совсем без внешних зависимостей?** Скачайте `gsap.min.js` и
`ScrollTrigger.min.js`, положите в `assets/js/` и поправьте два тега
`<script>` в конце `index.html`.

## 5. Доступность и производительность

- Семантическая разметка, `lang="ru"`, ссылка «Перейти к содержанию».
- Меню, аккордеон и фильтр расписания работают с клавиатуры
  (`Tab`, стрелки, `Home`/`End`, `Escape`), состояния описаны через ARIA.
- Видимая рамка фокуса на всех интерактивных элементах.
- Разметка, стили и скрипт — около **140 КБ** до сжатия; изображения ещё
  около 950 КБ, но грузятся лениво, кроме одного кадра первого экрана.
- Иконки и декор — inline-SVG и CSS-градиенты, без иконочных шрифтов.
- Ленты прокрутки без JS остаются обычными скроллящимися лентами:
  закрепление — только надстройка.
- Анимируются только `transform` и `opacity` — не вызывают перерасчёт вёрстки.
- Проверено: нет горизонтальной прокрутки на 390, 834 и 1440 px.

## 6. Публикация

Подойдёт любой статический хостинг.

```bash
# Netlify
npx netlify-cli deploy --dir . --prod

# Vercel
npx vercel --prod
```

в корень сайта по FTP.

## 7. Проверка после правок

```bash
python3 -m http.server 8000     # затем откройте http://localhost:8000
```

Что стоит проверить руками:

- [ ] Все кнопки «Вступить в клуб» ведут в нужный Telegram-канал
- [ ] Расписание совпадает с реальным
- [ ] Отзывы заменены на настоящие (или секция удалена)
- [ ] Указаны стоимость, контакты и реквизиты
- [ ] Страница открывается по ссылке с якорем, например `/#faq`
- [ ] Фотографии заменены на свои (8 мест, помечены `ЗАМЕНИТЬ НА ФОТО`)
- [ ] Заставка при загрузке снимается меньше чем за 2 секунды
- [ ] Мобильное меню открывается и закрывается
- [ ] В системных настройках включите «уменьшить движение» —
      страница должна остаться полностью читаемой
