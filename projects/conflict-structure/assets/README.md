# assets/

Необязательная папка. Презентация работает и без неё.

## Портреты авторов подхода

На слайде «Авторы подхода» вместо фотографий по умолчанию показываются
монограммы (АЯ / АИ). Если положить сюда файлы с такими именами, презентация
подставит их автоматически — без правки кода:

- `antsupov.jpg` — портрет А. Я. Анцупова
- `shipilov.jpg` — портрет А. И. Шипилова

Рекомендуемый размер: квадрат, минимум 200×200 px.

Если файла нет, тег `<img>` удаляется обработчиком `onerror`, и остаётся
монограмма — ошибок в консоли это не вызывает.

> Изображения намеренно не входят в репозиторий: у фотографий из исходной
> презентации неизвестна лицензия. Добавьте свои копии локально.
