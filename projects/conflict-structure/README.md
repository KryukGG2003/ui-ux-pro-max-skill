# Структура конфликта — презентация и лендинг

Презентация «Объективная и субъективная структура конфликта» (по А. Я. Анцупову
и А. И. Шипилову), переведённая из `.pptx` в код, и лендинг на её основе,
готовый к вставке в Tilda.

Авторы содержания: Кудякова Дарья, Бороздова Валерия (группа 8.536 зу).

## Файлы

| Файл | Что это |
|---|---|
| `struktura-konflikta.pptx` | **Готовая презентация для PowerPoint и Google Презентаций.** 17 слайдов, с заметками докладчика |
| `build-pptx.mjs` | Генератор `.pptx` (pptxgenjs) — если нужно что-то поправить и пересобрать |
| `add-animations.py` | Пост-обработка `.pptx`: анимации, переходы, чистка XML, дедупликация фонов |
| `make-backgrounds.mjs` | Генератор градиентных фонов (`assets/bg/*.jpg`) |
| `presentation.html` | Презентация: 17 слайдов, анимации, навигация с клавиатуры, режим обзора. Открывается двойным кликом, без сборки и интернета* |
| `tilda-embed.html` | **Источник правды для лендинга.** Код для блока `T123` в Tilda |
| `landing.html` | Тот же лендинг как отдельная страница. Собирается из `tilda-embed.html` |
| `build-landing.mjs` | Сборщик: `tilda-embed.html` → `landing.html` |
| `assets/` | Необязательные портреты авторов подхода (см. `assets/README.md`) |

\* Шрифты (Playfair Display + Manrope) подгружаются с Google Fonts. Без интернета
страницы работают на системных запасных шрифтах — вёрстка не ломается.

## Презентация в PowerPoint / Google Презентациях

Файл `struktura-konflikta.pptx` — просто открыть или загрузить:

- **PowerPoint** — двойной клик по файлу.
- **Google Презентации** — Файл → Открыть → Загрузка, перетащить файл.
  Google подставит свои шрифты вместо Cambria и Calibri; вёрстка не поедет,
  но при желании шрифты можно заменить через Формат → Шрифт.

В каждом слайде есть **заметки докладчика** — развёрнутый текст по теме слайда.
В PowerPoint они под слайдом, в Google Презентациях — там же («Заметки докладчика»).

Формат 16:9, 13,33 × 7,5 дюйма. Файл проверен валидатором OOXML.

### Анимации

Каждый слайд появляется каскадом: элементы проявляются волнами по 130 мс,
всё, что лежит внутри карточки, появляется вместе с ней. Между слайдами —
плавный переход. Клика не требуется: анимация стартует сама при показе слайда.

pptxgenjs анимации не поддерживает вообще, поэтому они дописываются в OOXML
отдельным шагом (`add-animations.py`). Тот же скрипт убирает дубли фоновых
картинок — без него файл весит 5,5 МБ вместо 540 КБ.

**В Google Презентациях** анимации и переходы импортируются, но проигрываются
упрощённо: каскад может идти ровнее, чем в PowerPoint. Если нужен точный
результат — показывайте из PowerPoint.

### Пересобрать .pptx

```bash
npm install pptxgenjs playwright
node make-backgrounds.mjs        # фоны (нужен только при их изменении)
node build-pptx.mjs              # сборка слайдов
python3 add-animations.py struktura-konflikta.pptx   # анимации + чистка
```

Порядок важен: `add-animations.py` запускается последним, по готовому файлу.

## Презентация в браузере (с анимациями)

Открыть `presentation.html`.

| Клавиша | Действие |
|---|---|
| `→` `Space` | Следующий слайд |
| `←` | Предыдущий слайд |
| `Home` / `End` | Первый / последний слайд |
| `O` | Сетка всех слайдов |
| `P` | Автопоказ (9 с на слайд) |
| `F` | Полный экран |
| `?` | Справка по управлению |
| `Esc` | Закрыть окно |

На телефоне — свайпы влево/вправо. Номер слайда пишется в адрес
(`presentation.html#7`), поэтому на конкретный слайд можно дать прямую ссылку.

### Что добавлено к исходной презентации

Исходные 9 слайдов переработаны в 17 и дополнены:

- разделены обзорные и разборные слайды по каждому элементу подструктур;
- добавлено прямое сравнение **объект vs предмет** таблицей — в исходнике это
  различие объяснялось текстом и легко терялось;
- добавлен слайд «Разбор кейса по элементам»: сквозной пример (раздел квартиры
  после развода), разложенный сразу по обеим подструктурам;
- добавлены слайды «Что важно запомнить» и источник;
- шесть SVG-схем вместо стоковых картинок: пересечение подструктур, роли
  участников, искажение образа, кривая напряжения, взаимная детерминация.

Иллюстрации из исходного `.pptx` не переносились: часть из них — сток с
водяным знаком. Вместо них — собственная векторная графика.

## Лендинг для Tilda

### Вставка

1. В Tilda: **Другое → T123 «HTML-код»**.
2. Скопировать **весь** `tilda-embed.html` и вставить в поле блока.
3. В настройках блока выставить внутренние отступы **Padding top / bottom = 0**
   (у секций блока свои отступы).
4. Опубликовать.

### Ссылка на презентацию

Кнопки «Открыть презентацию» берут адрес из атрибута `data-deck` на корневом
`<div class="cf">`:

```html
<div class="cf" data-deck="presentation.html">
```

Замените на свой адрес, например `data-deck="https://example.com/presentation.html"`.
Саму презентацию нужно где-то разместить — подойдёт любой статический хостинг
или раздел «Файлы» в Tilda.

### Почему это не ломает Tilda

- Все стили ограничены классом `.cf` — глобальных селекторов нет, на остальные
  блоки страницы код не влияет.
- Переменные оформления названы `--cf-*`, чтобы не пересечься с переменными Tilda.
- Внутри блока точечно сброшены `margin`/`font-family`/`line-height` у
  заголовков и абзацев — иначе их перебивает типографика Tilda.
- Скрипт обрабатывает каждый экземпляр блока отдельно (`data-cf-ready`),
  поэтому блок можно вставить на страницу несколько раз.
- Нет `position: fixed` и глобальных обработчиков — ничего не конфликтует с
  меню и попапами Tilda.

### Правки

Править нужно `tilda-embed.html`, затем пересобрать отдельную страницу:

```bash
node build-landing.mjs
```

`landing.html` перезаписывается целиком — руками его не редактируют.

## Доступность

- Разметка секций, `role="tablist"` с навигацией стрелками у переключателя
  подструктур, `aria-live` для номера слайда в презентации.
- Видимый фокус на всех интерактивных элементах.
- `prefers-reduced-motion: reduce` отключает анимации и параллакс, показывая
  сразу конечное состояние.
- Контраст текста к фону проверен по WCAG AA на фоне `#0B0E14`:
  основной текст `#EAEFF7` — 16.7:1, второстепенный `#93A2BC` — 7.5:1,
  подписи `#76859F` — 5.2:1, акценты `#4DA3FF` и `#FF7A59` — 7.4:1 и 7.5:1.
  Все выше порога 4.5:1 для обычного текста.
